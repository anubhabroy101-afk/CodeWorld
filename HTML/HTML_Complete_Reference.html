7️⃣ Semantic HTML (HTML5)

Semantic Structure

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Page</title> </head> <body> <header> <nav> <ul> <li><a href="#">Home</a></li> <li><a href="#">About</a></li> </ul> </nav> </header> <main> <article> <header> <h1>Article Title</h1> <time datetime="2026-04-27">April 27, 2026</time> </header> <p>Article content...</p> </article> <aside> <h3>Related Links</h3> <ul> <li><a href="#">Link 1</a></li> </ul> </aside> </main> <footer> <p>© 2026 My Website</p> </footer> </body> </html>

Semantic Elements Reference

<header> - Introductory content or navigation
<nav> - Navigation links
<main> - Main content of the page
<article> - Self-contained, independent content
<section> - Thematic grouping of content
<aside> - Sidebar or related content
<footer> - Footer information
<figure> - Self-contained illustration, diagram, photo
<figcaption> - Caption for figure
<details> - Additional details user can reveal
<summary> - Visible heading for details
<mark> - Highlighted or marked text
<time> - Date/time

Semantic Examples

<!-- Figure with caption --> <figure> <img src="image.jpg" alt="Description"> <figcaption>Image caption here</figcaption> </figure> <!-- Details and summary --> <details> <summary>Click to expand</summary> <p>Hidden content appears here</p> </details> <!-- Time element --> <time datetime="2026-04-27T10:30:00">April 27, 2026</time>

Performance & Loading

Storage & APIs

<!-- Local Storage attribute --> <script> // Store data localStorage.setItem('key', 'value'); // Retrieve data const value = localStorage.getItem('key'); // Remove data localStorage.removeItem('key'); </script> <!-- Session Storage --> <script> sessionStorage.setItem('key', 'value'); </script> <!-- IndexedDB --> <script> const request = indexedDB.open('database', 1); </script>

✅ Best Practices

1. Structure

  • Always use semantic HTML elements
  • Maintain proper nesting of elements
  • Use proper heading hierarchy (h1 → h2 → h3)
  • Keep HTML clean and indented

2. Accessibility

  • Always include alt text for images
  • Use proper labels for form inputs
  • Use ARIA attributes when needed
  • Ensure keyboard navigation works
  • Maintain sufficient color contrast

3. Performance

  • Optimize images (size and format)
  • Minimize external resources
  • Use lazy loading for images
  • Defer non-critical JavaScript
  • Minimize CSS files

4. SEO

  • Use descriptive meta descriptions
  • Implement proper canonical URLs
  • Use structured data (Schema.org)
  • Create XML sitemaps
  • Use descriptive link text

5. Security

  • Sanitize user inputs
  • Use HTTPS
  • Implement CSRF protection
  • Use Content Security Policy headers
  • Keep dependencies updated
